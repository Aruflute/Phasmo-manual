An Archipelago manual for Phasmophobia


Thingy that you might want to know :

- Item are separated by items/tier, not the "progressive something" format
- Lighters/Smudges are tagged early, but there's only 3 starter check so if you generate with a single yaml,
you might see something about not having enough early slots to place all of em'. This does not cause any problems.
- Nell's, Grafton, Point Hope, Bleasdale, both Meadows, Prison, Maple lodge, High school cannot be starter maps,
not enabling anything not in this list will cause problem if generating with a single yaml, if multiple yaml you will
just not have any starter map given in your starer locations
- Cursed posessions sanity is usually a bad idea unless you run custom mult and choose them yourself if you're not willing
to spam maps hoping to get the right one


Thing that might be confusing about "Gambler" sanity :

- The ol' objective = Photo of dirty water
- When i'm a fool = Draw a fool card on the first try
- Right in my heart = Voodoo doll heart pin first try
- Meow~ = Hear a cat's meow on Willow street
- Hated by a shade = Get hunted by a shade without using cursed posessions in the round
